# D3. 의료 접근성 — 서울 노인 도보 의료 생활권 분석

**담당: 이정태**  
**핵심 질문: 노인이 만성질환 관리를 동네에서 도보로 해결할 수 있는가?**

---

## 분석 개요

서울시 의원·병원·보건소·약국을 대상으로,  
**일반인(1.28 m/s)** 과 **노인 3개 속도 그룹** 의 30분 도달 가능 시설 수를 동 단위로 계산.  
결과를 `도달가능 점수 = (노인 도달 수 / 일반인 도달 수) × 100` 으로 표현한다.  
보행 반경은 **Tobler's Hiking Function** 으로 동별 경사도를 반영해 보정.

### 팀 표준 보행 속도 (한음 외 2020)

| 그룹 | 속도 | 30분 반경 (평지) | 비고 |
|------|------|----------------|------|
| 일반인 | 1.28 m/s | 2,304 m | 도달가능 점수 분모 (항상 100점) |
| 일반 노인 | 1.12 m/s | 2,016 m | |
| 보행보조 노인 | 0.88 m/s | 1,584 m | 메인 비교 대상 |
| 보행보조 하위 15% | 0.70 m/s | 1,260 m | 최약계층 |

> **도달가능 점수 해석**: 보행보조 노인의 의료 점수가 46점이면,  
> 일반인이 30분에 갈 수 있는 병원·약국 중 46%만 접근 가능하다는 뜻.

> **거리 측정 방식**  
> — 01~05 스크립트: 유클리드 + Tobler 경사 보정 (EPSG:5179)  
> — 06 통합 대시보드: **OSM 보행 네트워크(Dijkstra)** + Tobler 경사 보정  
> &nbsp;&nbsp;&nbsp;(서울 보행 그래프 162,624 노드 · 467,188 엣지)

## 실행 방법

```bash
# 가상환경 활성화
source venv/Scripts/activate   # Windows

# 패키지 설치 (최초 1회)
pip install -r requirements.txt

# 개별 분석 실행 (순서대로)
python src/01_medical_access.py        # 기본 접근성 분석 (일반인 vs 노인, 경사 보정)
python src/02_temporal_access.py       # 시간대별 접근성 (평일/저녁/주말)
python src/03_trip_chaining.py         # 삼각 동선 (병원→약국→집)
python src/04_slope_correction.py      # 경사도 보행속도 보정 (Tobler 독립 시각화)
python src/05_elderly_population.py    # 고령 인구 이중 취약지 분석

# 통합 대시보드 (독립 실행 가능, OSM 캐시 재사용)
python src/06_medical_dashboard.py     # 인터랙티브 통합 대시보드 v3 생성
```

> `06`은 캐시가 있으면 OSM Dijkstra를 재실행하지 않고 즉시 HTML을 출력합니다.
