# 서울 노인 도보 생활권 진단 — 최종 시각화 산출물 정리

## 프로젝트 개요

### 핵심 질문

> 서울시가 추구하는 **"30분 도보 생활권"** 비전은 노인에게도 유효한가?

서울시 도시계획은 보행 속도 **1.28 m/s**(성인 표준)를 기준으로 설계되어 있다. 그러나 건강한 노인은 **1.12 m/s**, 보행보조기 사용 노인은 **0.88 m/s**, 장애 수준의 노인은 **0.70 m/s**로 보행한다. 속도가 느려질수록 30분 안에 도달할 수 있는 생활 시설의 수는 급격히 줄어든다 — 일반인 대비 **76.7% → 46.9% → 25%** 수준으로.

이 프로젝트는 서울 25개 자치구 × 428개 행정동 단위에서 **노인 보행 속도별 생활 인프라 접근성**을 정량적으로 진단한 2026 서울 빅데이터 활용 경진대회 출품작이다.

### 분석 축

| 축 | 도메인 | 담당 |
|---|---|---|
| ① | 대중교통 (Transit) — 노인 교통 이용 패턴 및 네트워크 분석 | 유호준 |
| ② | 기후 (Climate) — 폭염·한파 대피 시설 및 결빙 위험 구역 | 김성령 |
| ③ | 인프라 (Infra) — 전통시장·슈퍼·은행·복지관 접근성 | 심재현 |
| ④ | 복지 (Bokji) — 경로당·노인복지관·공원 접근성 | 양석준 |
| ⑤ | 의료 (Medical) — 의원·병원·약국 1차 의료 접근성 | 이정태 |

## 기술 스택

- **프레임워크**: SvelteKit 2 + Svelte 5 Runes (TypeScript 미사용, JSDoc 방식)
- **지도**: Leaflet 1.9 + CartoDB Light 배경 타일
- **차트**: Chart.js 4
- **경로 분석**: Dijkstra (OSM 도로망 266,780 노드) + Convex Hull 등시선
- **압축**: Pako (gzip 해제, ~3.2 MB OSM 그래프)
- **배포**: SvelteKit Static Adapter (전체 사전 렌더링)

### 5. 인프라 — Infra (/infra)

**담당**: 심재현  
**목적**: 전통시장·슈퍼마켓·은행·주민복지관에 대한 실제 도로망 기반 접근성 정밀 분석

**이 프로젝트의 기술적 핵심 페이지**

**주요 시각화**:

| 시각화 | 내용 |
|---|---|
| Leaflet 지도 + 등시선 | OSM 도로망 Dijkstra로 계산한 실제 도달 가능 구역 폴리곤 |
| 직선 거리 vs 실거리 비교 | 점선 원(직선) vs 채워진 폴리곤(실도로) |
| 레이더 캔버스 | 선택 지점 기준 360도 방위별 주변 시설 분포 |
| 동별 막대 차트 | 도달 가능 시설 수 순위 |
| 은행 지점 추이 선 차트 | 서울 전체 + 선택 구 은행 수 변화 |
| 순위 테이블 | 구/동 단위 시설 수 + 복합 점수 + 접근성 등급 |

**컨트롤 패널**:
- 보행 유형 4종 선택 (1.28 / 1.12 / 0.88 / 0.70 m/s)
- 시간 설정 (15 / 30 / 45분)
- 구 ↔ 동 단위 전환
- Tobler 경사 보정 체크박스
- 시설 레이어 선택 (전체 / 시장 / 은행 / 복지관 / 슈퍼)

**주요 수치**: 전통시장 195개 · 은행 1,579개 · 복지관 426개 · 슈퍼마켓 31,024개  
**핵심 기술**: Haversine 거리 + Tobler 경사 함수 + Dijkstra 최단 경로 + Convex Hull 등시선  
**테마 색상**: 민트 `#3ecfa0`

### 6. 복지 — Bokji (/bokji)

**담당**: 양석준  
**목적**: 경로당·노인복지관·소규모 복지관과 공원에 대한 노인 접근성 및 취약 지역 진단

**주요 시각화**:

| 시각화 | 내용 |
|---|---|
| Leaflet 지도 | 복지 시설 유형별 마커 + 공원 면적 비례 원 마커 |
| 속도별 접근성 드롭오프 차트 | 보행 속도 감소에 따른 점수 하락 곡선 |
| 버블 스캐터 차트 | 복지 접근 수(x) × 공원 접근 수(y), 버블 크기 = 노인 인구 |
| 레이더 차트 | 선택 구 vs 서울 평균 (복지·공원 × 3개 속도 6축) |
| 동별 막대 차트 | 취약도 또는 점수 기준 정렬 |
| 순위 테이블 | 25개구 취약도 지수 + 복지/공원 접근 점수 |

**취약도 산출식**: 복지 박탈 50% + 공원 박탈 50% (Min-Max 정규화)  
**주요 수치**: 복지 시설 800개+ · 공원 300개+ · 분석 동 428개  
**테마 색상**: 보라 `#b48ef4`

### 7. 의료 — Medical (/medical)

**담당**: 이정태  
**목적**: 의원·병원·보건소·종합병원·약국에 대한 1차 의료 접근성 분석과 취약 구역 도출

**주요 시각화**:

| 시각화 | 내용 |
|---|---|
| Leaflet 코로플레스 + POI | 동별 접근 점수 색상 + 5종 의료 시설 마커 |
| 동별 점수 막대 차트 | 선택 구 내 동별 접근 점수 (등급별 색상) |
| 영향 분석 차트 | 구별 "접근 취약 노인 가중치" = (100 - 점수) / 100 × 노인 인구 |
| 버블 차트 | x = 노인 인구, y = 점수, 버블 크기 = 영향 지수 |
| 순위 테이블 | 5종 시설 수 + 의원/약국/복합 점수 + 접근 등급 |

**등급 체계**: 양호(65+) / 보통(50-65) / 미흡(50 미만)  
**주요 수치**: 의원·병원 7,000개+ · 약국 8,000개+  
**테마 색상**: 핑크 `#f472b6`

### 8. 종합 — Conclusion (/conclusion)

**목적**: 기후·인프라·복지·의료 4개 도메인을 종합한 서울 25개구 접근성 순위 및 정책적 함의 도출

**주요 시각화**:

| 시각화 | 내용 |
|---|---|
| 속도별 점수 손실 막대 차트 | 일반 100 → 노인 68 → 보조기 38 → 하위15% 25 (누적 손실) |
| 도메인별 서울 평균 카드 | 4개 도메인 × 선택 보행 유형 + 경사 보정 토글 |
| Leaflet 코로플레스 지도 | 25개구 복합 점수 색상 (클릭 시 상세 카드) |
| 레이더 차트 | 선택 구(주황) vs 서울 평균(청록) 4축 비교 |
| 순위 테이블 | 25개구 도메인별 점수 + 복합 순위 + 접근 등급 |

**인터랙션**: 보행 유형 3종 + 경사 보정 토글 → 지도·차트·테이블 전체 실시간 갱신  
**점수 색상 체계**:
- 73점 이상: 짙은 청록 (양호)
- 65–73점: 청록 (보통)
- 58–65점: 황색 (주의)
- 50–58점: 주황 (미흡)
- 50점 미만: 짙은 빨강 (취약)

## 핵심 발견

1. **속도 감소의 비선형 충격**: 보행 속도가 줄어들수록 접근 가능 시설 수는 선형이 아닌 급격한 감소를 보인다. 보조기 사용 노인(0.88 m/s)은 일반인 대비 접근성이 약 46.9%에 불과하다.

2. **구별 격차의 실재**: 종합 점수 상위 구와 하위 구 간 격차는 동일 보행 속도 조건에서도 20점 이상 벌어진다.

3. **경사의 숨겨진 역할**: Tobler 경사 보정을 적용하면 구릉 지형이 많은 구(예: 성북구, 종로구 일부)의 점수가 추가로 하락한다. 평지 기준 분석은 실제 격차를 과소평가한다.

4. **은행 지점 감소**: 인프라 도메인에서 서울 전역 은행 지점 수의 감소 추이가 확인된다. 고령 인구가 많은 구에서 영향이 특히 크다.

5. **대중교통과 도보의 보완 관계**: 교통 도메인 분석은 버스 정류장 반경 내에 앵커 시설이 집중되는 경향을 보여준다 — 도보 접근성이 나쁜 지역에서 대중교통 의존도가 높아짐을 시사한다.
