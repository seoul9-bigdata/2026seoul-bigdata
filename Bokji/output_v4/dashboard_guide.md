# 복지·녹지 인프라 대시보드 가이드 (v4)

> 파일: `output_v4/infra_dashboard_bokji.html`  
> 분석 범위: 서울시 426개 행정동 · 노인여가복지시설 185개소 + 공원 132개소 · 30분 보행 기준

---

## 1. 대시보드 구성 및 의도

### 1-1. 컨트롤 패널

대시보드 상단의 인터랙티브 조작 영역. 아래 선택에 따라 모든 차트·지도·표가 실시간으로 갱신된다.

| 컨트롤 | 선택지 | 의도 |
|--------|--------|------|
| 보행자 유형 | 일반인(1.28 m/s) / 일반노인(1.12 m/s) / 보조기구(0.88 m/s) / 보조 하위15%(0.70 m/s) | 이동능력별 접근성 격차 비교 |
| 시설 유형 | 복지+공원 / 복지시설만 / 공원만 | 분석 대상 인프라 선택 |
| 경사로 보정 | ON / OFF | Tobler 경사 보정 적용 전후 비교 |
| 동 단위 반경 | ON / OFF | 행정동별 실제 보행반경을 지도에 오버레이 |
| 기준 자치구 | 25개 자치구 드롭다운 | 구 단위 집중 분석 |

**통계 박스 (4개)**: 선택 구 기준으로 평균 도달 복지시설 수 / 공원 수 / 복지 도달가능점수 / 공원 도달가능점수를 즉시 표시. 일반인 선택 시 점수는 항상 100이므로 숨김 처리.

---

### 1-2. 서울시 복지·녹지 시설 분포 지도

**무엇을 보여주는가**  
Leaflet 기반 지도에 복지시설·공원의 실제 위치를 마커로 표시하고, 선택한 자치구 중심점에서 현재 보행자 유형의 30분 도달 반경을 점선 원으로 그린다.

**어떤 의도로 만들었는가**  
- 시설이 특정 지역(도심·강남)에 집중되어 있고 외곽·북부에는 공백이 있음을 시각적으로 확인하려는 목적
- 경사 보정 ON 시 구 내 평균 tobler 비율을 반영해 반경이 줄어드는 것을 보여줌으로써, 경사지 자치구(종로·성북·도봉 등)에서 실제 도달 거리가 얼마나 감소하는지 직관적으로 전달
- "동별 반경 표시" ON 시 각 행정동 중심점 기준으로 개별 원을 그리며, 도달가능점수에 따라 초록(≥80) / 주황(50~79) / 빨강(<50)으로 색상을 달리해 동 수준의 공간적 불평등을 드러냄

**범례**
- 파란 점: 노인복지관 / 주황 점: 노인교실 / 옅은 파란 점: 소규모복지관 / 초록 점: 공원 (크기 = 면적 비례)
- 주황 점선 원: 선택 구 중심점 기준 30분 보행반경

---

### 1-3. 선택 자치구 4속도 비교 차트

**무엇을 보여주는가**  
선택한 자치구 내 행정동 평균 도달 시설 수를 4가지 보행 속도별로 막대 차트로 비교. 복지시설(파랑)과 공원(초록)을 동시에 표시.

**어떤 의도로 만들었는가**  
- 속도가 느려질수록 도달 가능한 시설이 급감하는 '계단 효과'를 명시적으로 보여주기 위함
- 경사 보정 ON/OFF 전환 시 노인·보조기기·하위15% 막대가 더 짧아지는 것을 보여줌으로써, 경사 보정이 취약계층에게 미치는 추가적 불리함을 수치로 확인

---

### 1-4. 자치구별 평균 도달 시설 수 차트

**무엇을 보여주는가**  
서울시 25개 자치구 전체를 평균 도달 시설 수 기준으로 내림차순 정렬한 가로 막대 차트. 현재 선택된 구는 주황색으로 강조.

**어떤 의도로 만들었는가**  
- 자치구 간 접근성 불평등 구조를 한 눈에 파악하려는 목적
- 어떤 자치구가 절대적으로 인프라가 풍부하고 어디가 취약한지를 비교 가능한 형태로 제시
- 보행자 유형·시설 유형·경사 보정 토글에 연동되므로 "일반인 기준 최상위 구가 보조기구 기준에서는 어떤 순위인가"를 확인 가능

---

### 1-5. 도달가능점수 하위 10 행정동 차트

**무엇을 보여주는가**  
- **일반인 선택 시**: 취약도 지수 상위 10개 행정동 (취약도 = 복지박탈 50% + 공원박탈 50%, Min-Max 정규화, 0~1)
- **노인·보조기구·하위15% 선택 시**: 도달가능점수 최하위 10개 행정동

**어떤 의도로 만들었는가**  
- 정책 개입이 가장 시급한 지역을 pinpoint하기 위한 목적
- 일반인 기준에서는 취약도(절대적 시설 부재)를 기준으로, 노인·취약계층 기준에서는 일반인 대비 상대적 접근 격차(도달가능점수)를 기준으로 우선순위를 달리함
- 점수 색상: 초록(≥80점) / 주황(50~79점) / 빨강(<50점)

---

### 1-6. 행정동별 복지·녹지 접근성 상세표

**무엇을 보여주는가**  
서울시 전체 행정동을 행별로 나열한 정렬 가능한 테이블.

| 컬럼 | 설명 |
|------|------|
| 구명 / 동명 | 자치구 및 행정동명 |
| 65세이상 | 65세 이상 인구 수 |
| 고령화율 | 65세이상 / 전체인구 × 100 |
| 복지점수 / 공원점수 | 도달가능점수 (노인·보조 선택 시) 또는 취약도 (일반인 선택 시) |
| 복지 도달수 / 공원 도달수 | 현재 설정으로 30분 내 도달 가능한 시설 수 |
| Tobler | 해당 동의 경사 보정 비율 (1.0 = 평지 기준) |

**어떤 의도로 만들었는가**  
- 취약계층이 선택되면 도달가능점수 오름차순으로 정렬해 가장 격차가 큰 동을 상위에 표시, 정책 대상 지역을 구체적으로 확인 가능
- 복지 도달수가 0인데 일반인 도달수가 1 이상인 경우(즉, 일반인은 갈 수 있지만 취약계층은 못 가는 경우)를 빨간색 강조로 표시
- Tobler 컬럼으로 경사도가 심한 동을 즉시 파악 가능

#### 2-6. 동별 Tobler 경사 보정 비율

| 항목 | 내용 |
|------|------|
| 파일명 | `medical_LEE/outputs/tobler_ratio_LEE.csv` |
| 생성 스크립트 | `medical_LEE/src/04_slope_correction.py` |
| 생성 주체 | 의료 접근성 분석팀 (LEE) |
| 사용 스크립트 | `compute_tobler_v4.py` |
| 주요 컬럼 | `dong_code`, `full_name` (구명+동명), `tobler_ratio` |
| 역할 | 각 동의 경사도를 반영한 보행속도 보정 계수 — 평지 = 1.0, 급경사 = 0.4~0.7 |

**이 파일이 만들어진 방법 (04_slope_correction.py 요약)**

| 단계 | 내용 |
|------|------|
| 원본 데이터 | 서울시 표고점 5000 (`N3P_F002.shp`) + 행정동 경계 SHP |
| 공간 결합 | 표고점 → 행정동 `sjoin` → 동별 HEIGHT min/max 집계 |
| 경사 추정 | `slope ≈ (h_max - h_min) / (√area_m2 × 1.13)` (원형 동 가정) |
| Tobler 함수 | `V = 6 × exp(-3.5 × \|slope + 0.05\|)` km/h |
| 정규화 | `tobler_ratio = V(slope) / V(0)` |
| 결측 처리 | 표고점 없는 동 → 중위값으로 보간 |

```
tobler_ratio 범위 예시:
  삼청동(종로): 0.452  ← 급경사
  사직동(종로): 0.687
  가회동(종로): 0.735
  종로1·2·3·4가동: 0.856  ← 비교적 평탄
```
